# ⚔️ Weekly Quest Tracker (WoW Retail Addon)

إضافة مخصصة لـ **World of Warcraft Retail** لتتبع المهمات الأسبوعية عبر جميع شخصيات حسابك (Alts)، متوافقة تماماً 100% مع سياسات وبنود خدمة بليزارد (Blizzard ToS).

---

## 📁 طريقة التركيب (Installation)

1. خذ فولدر `WeeklyQuestTracker` بالكامل.
2. انقله (Copy / Paste) إلى مجلد إضافات اللعبة:
   ```text
   C:\Program Files (x86)\World of Warcraft\_retail_\Interface\AddOns\
   ```
   *(أو المسار الذي قمت بتثبيت اللعبة فيه)*
3. شغّل اللعبة أو ادخل على شخصيتك، وافتح قائمة **AddOns** في شاشة اختيار الشخصيات وتأكد إن `Weekly Quest Tracker` مفعّل.

---

## 🌟 المميزات الرئيسية

### 1. الأنماط الأربعة للعرض (4 View Modes):
في أعلى نافذة الإضافة، تجد 4 أزرار تتيح لك التبديل بين الأنماط أو عرضها معاً:
* 📊 **Grid (الشبكة):** جدول كامل لجميع شخصياتك ومهماتهم (✅ Done / ❌ Incomplete / ⏳ In Progress).
* 🎴 **Cards (كروت الشخصيات):** كارت لكل شخصية مع شريط نسبة الإنجاز وقائمة المهمات.
* 📝 **Quick To-Do (الموجز السريع):** يركز فقط على الشخصيات التي لديها مهمات غير مكتملة لتوفير وقتك.
* 📑 **Combined (الكل معاً):** يعرض موجز الـ To-Do في الأعلى وتحته جدول الشبكة الكامل في نفس الشاشة!

### 2. التصفير الأسبوعي التلقائي (Automatic Weekly Reset):
* الإضافة تتصل بـ API بليزارد الداخلي لمعرفة موعد الـ Weekly Reset لسيرفرك تلقائياً (سواء سيرفرات EU الأربعاء أو US الثلاثاء).
* مع بداية كل أسبوع جديد، يتم تصفير حالات المهمات لجميع الشخصيات تلقائياً دون أي تدخل منك.

### 3. إمكانية إضافة وحذف أي مهمة بسهولة:
* **إضافة مهمة جديدة:** اضغط على زر **`+ Add Quest`** في أعلى النافذة، واكتب رقم الـ Quest ID واسم المهمة، وسيتم إضافتها فوراً لجميع الشخصيات.
* **حذف مهمة:** كليك يمين (Right-Click) على عنوان المهمة في الجدول لاختيار حذفها.
* **حذف شخصية (Alt):** كليك يمين على اسم الشخصية لحذفها في حال مسحت الشخصية من اللعبة.

### 4. زر المينيماب (Minimap Icon):
* **كليك شمال:** فتح / إغلاق نافذة التتبع.
* **كليك يمين:** التبديل السريع بين أوضاع العرض (Grid / Cards / To-Do / Combined).
* **تمرير الماوس (Hover):** يعرض Tooltip سريع بالمهمات المكتملة والمتبقية للشخصية الحالية فوراً.
* **سحب بالماوس (Drag):** يمكنك تحريك الأيقونة ووضعها في أي مكان حول الخريطة المصغرة.

## ⌨️ أوامر الشات (Slash Commands)

| الأمر | الوظيفة |
| :--- | :--- |
| `/wqt` | فتح أو إغلاق نافذة التتبع |
| `/wqt scan` | فحص وتحديث بيانات الشخصية الحالية فوراً |
| `/wqt add <QuestID> [Name]` | إضافة مهمة جديدة مباشرة من الشات |
| `/wqt reset` | التحقق من التصفير الأسبوعي يدوياً |

## 🔒 الأمان والتوافق مع قوانين اللعبة (Safety & ToS)

* مكتوبة بالكامل بلغة **Lua** المعتمدة من Blizzard داخل بيئة الـ Addons الآمنة (Sandboxed).
* لا تحتوي على أي برامج تشغيل خارجية (`.exe`) ولا تعدل ملفات اللعبة أو الذاكرة.
* تستخدم دوال الاستعلام الرسمية المصرح بها من بليزارد مثل: `C_QuestLog.IsQuestFlaggedCompleted(questID)`.
* **نسبة الأمان: 100% وبدون أي خطر للباند نهائياً.**
